# IRM2 — project report

Mathematician-facing writeup of the model, the identifiability problems found
during development, the objective terms added to resolve them (volatility
anchor, LSMC futures consistency, P/Q term premium), and open questions.

- `project_report.tex` — LaTeX source (standard `article`; needs `amsmath`,
  `amssymb`, `booktabs`, `hyperref`, `enumitem`). Build: `pdflatex project_report.tex`.
- `project_report.html` — self-contained HTML (MathJax via CDN); open in a browser.

The Sphinx site mirrors the formulation at `docs/source/concepts/formulation.md`.
